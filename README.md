Designing Software at AI Speed — I Prompt, Steer & Orchestrate, the Machines Type
-------------------------------------------------

I’m Andy, a Frankfurt-based software designer and (now) AI-loop-orchestrator with 25+ years in IT consulting, software development, and data management. Somewhere along the way I stopped writing code and started conducting it: my craft today is prompting, steering, designing, and orchestrating the AI systems that generate the code for me. I still read every line—I just rarely touch it. I’m leading development at Tradatomy, where we build AI-driven trading software that empowers traders, and I spend my days fully immersed in the world of AI-generated super-coding—designing the loops, shaping the intent, and letting the agents do the keystrokes. Longtime open-source believer since its early days. When I’m not orchestrating agents, you’ll find me exploring new tech, climbing, or enjoying time with my family. Feel free to ask about my private repos and non-public project www.tradatomy.com - or get in touch—I’m always open to collaborating on something interesting!
